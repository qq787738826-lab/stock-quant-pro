# 使用说明

1. 启动后先看“行情总览”的服务状态。
2. 在“智能选股”查看评分、买入区间、止损与目标位。
3. 在“回测中心”用至少一段完整牛熊周期测试，不能只看单次结果。
4. 在“持仓管理”生成委托；只有点击“人工确认”后状态才改变。
5. 最终下单必须在券商客户端再次核对代码、价格、数量和方向。
6. 免费行情可能延迟或中断。异常时软件使用演示数据，仅用于验证流程，不能据此实盘。

## 1.4.0 研究版立即选股

1. 在仓库根目录运行 `& .\quant-server\scripts\start-stock-quant-pro.ps1`；如果 Resident Broker
   正在由 watchdog 恢复，启动器会自动等待后继续，不需要手工启动 Broker。
2. 等首页显示 `READY` 后点击“立即选股”；默认使用最近 20 日主窗口、60 日辅助窗口。
3. 系统自动检查固定 25 股池的数据，必要时在月度门禁内做增量、幂等补齐。
4. 先看确定性“量化 Top 10”，再看最终 0—5 只候选的 Agent、Risk、Strategy 与 Critic 结论。
5. “今日无合格候选 / INSUFFICIENT_EVIDENCE”表示证据不足，不是系统故障。
6. 历史选股可在同一页回看；20/60/120/250 日入口均是当前时点回顾研究，不冒充历史 Live Shadow。

立即选股只生成研究结论与 Paper 模拟。真实交易固定关闭，不连接券商，也不会使用真实资金。
若固定 Broker 计划任务确实缺失、禁用、定义异常或超过自动恢复时限，启动器只显示
`ACTION_REQUIRED`、明确 reason 和修复提示，不输出内部 PowerShell 堆栈。

## 1.3.0 模拟交易流程

1. 在“智能选股”中对通过严格过滤的股票点击“交易计划”。
2. 进入“持仓管理”，核对买入区间、止损和目标价。
3. 点击“生成委托”，系统根据建议仓位自动计算100股整数倍数量。
4. 待确认委托只冻结模拟资金，不会直接成交。
5. 点击“确认成交”后，模拟账户自动扣款并建立持仓。
6. 当日新增数量不可卖，下一交易日自动按T+1规则解锁。
7. 点击“刷新行情并检查风险”，查看止损、止盈和移动止盈提示。
8. 点击持仓行“带入卖出”，核对数量和价格后创建并确认卖出委托。
9. 在模拟成交流水和权益曲线中复盘结果。
